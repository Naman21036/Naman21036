## About Me

I'm an aspiring **AI/ML Engineer** focused on building intelligent, production-ready systems at the intersection of large language models, retrieval-augmented generation, and scalable ML infrastructure. I care deeply about writing clean, efficient code and shipping real-world AI products that make an impact.

- Building AI-powered applications using **RAG, LLMs, and modern ML pipelines**
- Exploring **MLOps, System Design**, and scalable AI system architecture
- Strong foundation in **Data Structures, Algorithms**, and Competitive Programming
- Passionate about **applied AI** — probabilistic modeling, optimization, and data-driven decision making
